# ArtemisSignals launch site

Static, responsive coming-soon website for `artemissignals.ai`.

## Deployment

Amplify monorepo application root: `launch`

Build output: `.` (folder contents)

No build command needed. Publish `launch/index.html` via GitHub to your Amplify-connected `main` branch.

## Waitlist status

The early-access CTA uses a `mailto:` link. It is **not** a database-backed registration. Replace it with a verified-opt-in waitlist API form when the backend is ready.

The sample contact address `hello@artemissignals.ai` must exist before inviting visitors to use it.
